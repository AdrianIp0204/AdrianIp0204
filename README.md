## Selected projects

### [ExamLantern](https://examlantern.com/)

An Edexcel International A Level learning platform with lessons, worked examples, interactive explanations, and practice across science and mathematics.

I'm building it to help students understand the ideas behind the answers. The project brings together web development, science education, and AI-assisted educational video production.

### [PlanBranch](https://github.com/AdrianIp0204/PlanBranch)

A visual workspace for planning, directing, and reviewing coding agents. Editable diagrams connect ideas to implementation tasks, with individual tasks run in isolated Git worktrees and changes reviewed before they're applied.

I'm building it to make the reasoning and decisions behind AI-assisted coding easier to follow.

**Built with:** Python, Flask, React, TypeScript, and SQLite.
